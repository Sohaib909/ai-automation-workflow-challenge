Working demo

  A[Brief + brand kit · past ideas + ratings · approved performance learnings]:::data --> B[Assemble context · assign 1 creative lens per idea]:::auto
  B --> C[LLM generates ideas · concept · hook · visual · video · test hypothesis]:::ai
  C --> D[Schema validation · claim check · near-duplicate check · weighted score]:::auto
  D --> E{{Strategist: approve · reject · request changes · rate 1-5}}:::human
  E -- approved --> F[Copy · Static · Script · Landing]:::data
  E -- ratings and rejections --> B
AI doesGenerates 3–6 distinct concepts, each forced through a different lens (myth-buster, tangible impact, first-person POV and so on), and scores them against 8 criteria with a reason for each score.
Human doesApproves, rejects with a reason, or rates each idea. Ratings and rejections steer the next batch.
Quality controlsOnly facts listed in the brief's proof points may be used. Invented figures and banned claims are flagged. Scores help triage and are not presented as predictions.
Preferred toolsClaude Opus 5.5 for idea generation (strong reasoning over long briefs, follows brand rules). OpenAI GPT as a second source of different ideas. Demo: Ollama Cloud (gpt-oss:120b).

AI doesWrites 3–5 angled variations from the approved idea and can rewrite a single field on instruction, such as "make the hook shorter".
Human doesEdits, compares versions and approves. Copy with a QC error such as a banned claim cannot be approved.
Quality controlsEvery edit creates a new version and resets approval, so approved copy can't change silently. Each version records which provider and model produced it.
Preferred toolsClaude Sonnet 5.5 for copy (natural tone, sticks to the facts given, good value at volume). Claude Haiku 5.5 for bulk checks. Demo: Ollama Cloud.

Quality controls

How we reduce bad outputs, errors and hallucinations

Facts only from the briefThe AI may only use figures and claims listed as proof points. Any other number is flagged, and in summaries checked against the real data.
Brand rules enforcedEach client's banned phrases block approval until fixed. Absolute claims (“guaranteed”, “best”, “100%”) and invented testimonials are flagged.
Structured, validated outputEvery AI answer must match a strict format. Invalid answers are retried once, then fail visibly; mock output is never passed off as AI.
Different, not repetitiveIdeas use different creative angles, near-duplicates of past ideas are flagged, and reviewer ratings steer the next batch.
Platform-readyMeta length limits, valid buttons, exact ad sizes and Stories safe zones are checked automatically. Text on ads comes from a template, never from the image model.
Nothing changes silentlyEdits and regenerations create new versions and reset approval. Every decision and AI call is logged.
Data you can trustBad and duplicate rows are rejected, missing values stay “unavailable” rather than zero, and ratios are calculated from totals.
Humans hold the keysThe Media Buyer is read-only. Nothing is published, launched or changed in an ad account without a person.

Keeping it healthy

  • Each task has its own model setting, so a model can be swapped without code changes
  • Prompts are versioned and checked against a fixed set of past briefs before any model switch
  • Every AI call is logged with provider, latency, tokens and failures
  • Reviewer ratings and rejections are the quality metric to track week by week
  • Rule thresholds live in config and are tuned from "useful / not useful" feedback

Scale and cost

  • Text AI (ideas, copy, summaries) costs pennies per brief on small models. Free tiers cover a pilot
  • Images: a few pence each on hosted APIs, or close to zero on a local GPU
  • Avatar and generative video is the main cost, usually paid per minute or by subscription, so it is used selectively
  • Meta API access is free but rate-limited, handled with a nightly batch pull
  • Every client's data is kept separate. Costs are logged per client and campaign

Prices are indicative. Check current vendor pricing before committing.

Next steps

If I joined CerealBox, what I'd do next

  1. Week 1: learn the real work. Sit with strategists, copywriters and media buyers. Collect 10–20 past briefs and their best-performing ads to use as a test set for every AI change.
  2. Plug in the real data. Connect the Meta Marketing API (read-only) so Toast refreshes every client nightly, and send Media Buyer alerts to Slack.
  3. Upgrade the writing agents. Switch ideas and copy to Claude, compare the results side by side with the team on the test set, and keep whichever wins.
  4. Brand kits per client. Load logos, fonts and colours so image ads and landing pages come out fully on-brand.
  5. Connect video production. Add the render step for UGC (HeyGen and ElevenLabs) and for editing (Whisper and FFmpeg), starting with one pilot client.
  6. Make it team-ready. Logins and roles, a hosted database, and a weekly client report built from Toast.
  7. Measure and improve. Track hours saved, approval rate and edits needed for each agent, then improve the weakest agent each month.
